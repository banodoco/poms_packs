# Showing agent work

Use when the audience needs to understand how direction becomes creative output. Follow [directing](../directing-astrid-videos/SKILL.md) and the shared [visual language](../../references/visual-language.md). Use `agent-at-work`, not a fake terminal or transcript of hidden reasoning. The terminal is charcoal and readable; the output remains a clean editorial space. Let the creative evidence lead.

1. Choose the actual request and a few consequential recorded actions. Condense tool activity into short, truthful lines; distinguish working, failed, waiting and completed. Each completion reveals the real corresponding output, using stable IDs. No fabricated timings, successes or assets. Label illustrative examples as such.
2. Pick the output shape that best explains the activity: `cards` for references, variants, prompts and feedback; `timeline` for assembling an actual edit. Use [the activity contract](../../references/agent-at-work.md), [card example](../../references/example-agent-cards.yaml) and [timeline handoff](../../references/example-agent-at-work.yaml). For timelines derive tracks, times and players from the actual source edit and use [timeline visualization](../../references/timeline-visualizers.md). Keep the same objects throughout collection, docking and playback; do not rebuild an unrelated illustration at the handoff.
3. Compose other beats using [choreographing compositions](../choreographing-astrid-compositions/SKILL.md). Optional mascot activity should be sparse: a wave introducing Astrid, a run to the output, a brief inspection, an exit before playback. Call [performing with the mink](../performing-with-astrid-mink/SKILL.md) for cues; do not draw it inside the terminal renderer or add a sprite for every action. The story must still work if all mascot cues are removed.
4. Review text dwell time, readable output size, matched event/output IDs, same timeline geometry and playback clock, failure/approval states, and the moment the terminal recedes. Keep actual speech, audio and real result review outside the illustrative effect. Use [reviewing Astrid videos](../reviewing-astrid-videos/SKILL.md). The effect is an authored replay, not a live agent execution. Native placement and real managed-media resolution still require the supported host path.
