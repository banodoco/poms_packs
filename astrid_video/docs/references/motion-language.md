# Motion language

**The content glides. The pixels act.** Use crisp stepped motion alongside polished smooth interpolation. Effects explain a change; they are not decoration required at every cut. Read [living pixels](living-pixels.md): give pixel motion a task, a contact point, effort, a destination and a resting state. The pixels may adopt different organic forms; the media and layout remain polished.

| Verb | Visual behaviour | Typical use |
| --- | --- | --- |
| Materialise | A small ordered patch of square pixels becomes a complete object | Introduce a new tool or node |
| Crawl | A directional, irregular frontier reveals the next image underneath it, without a blank interval | Reference and output montage |
| Carry | A colony gathers underneath an object and transports it to a readable destination | Move or shuffle media cards |
| Hold | Porous currents form from a shared colony and pool behind several items in view | Present references or choices |
| Assemble | Smoothly moving items meet; a small square-pixel snap or spark marks the connection | Workflow, timeline, assembly |
| Pulse | A brief stepped signal near the important detail | Emphasis, completion, attention |
| Dissolve | The object breaks into a bounded field of square fragments | Exit or removal |
| Transform | A deliberate pixel front carries the old form into the new | Conceptual change, cinematic surprise |

These are design verbs, not six implemented APIs. Reuse implemented primitives when available; author new reusable ones only when necessary. The current shuffle is the canonical crawl; the chapter card materialises a pixel motif and the network animates a pixel signal along connections. Prefer a hard cut for jokes and real footage; smooth expansion for changing focus. Keep timing configurable and clip-relative. As starting points, quick reveals may take 0.2–0.35 s, more expressive ones 0.4–0.6 s; hold the final readable frame long enough for the spoken beat. Never sacrifice understanding for speed.

Use true square pixels, clean discrete edges, a consistent art grid and deterministic spatial randomness. Reserve brighter orange sparks for the active boundary; use sparse contrast, not strobe. Smooth movement must not unintentionally blur native character pixels. Preserve the outgoing content until replaced. Test both directions and endpoints, including short holds, random seeds, different aspect ratios and seeking. The mink's body poses may step while surrounding objects glide, as in the site's juggler. Sound accents, if needed, should be tactile and modest; allow silence and natural footage sound.
